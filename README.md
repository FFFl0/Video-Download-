# Скачивание видео — расширение для Google Chrome

Находит видеофайлы (MP4, WebM, MOV, MKV и др.) на открытой странице и позволяет скачать их.

## Возможности

- Перехват видео из сетевых запросов и из тегов `<video>` / `<source>` на странице (включая iframe).
- Всплывающее окно со списком найденных видео; число видео показывается на значке расширения.
- Разрешение (например, 1280×720), метка качества (720p, 1080p, 4K), размер файла и длительность.
- Редактируемое имя файла; по желанию — диалог «Сохранить как» для выбора папки.
- Интерфейс на русском и английском (выбирается по языку браузера).

## Установка

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Откройте `chrome://extensions`.
3. Включите «Режим разработчика» (переключатель справа вверху).
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension`.
5. Закрепите значок расширения на панели (иконка пазла → булавка).

## Как пользоваться

1. Откройте страницу с видео и запустите воспроизведение.
2. Нажмите на значок расширения — появится список найденных видео.
3. При необходимости измените имя файла и нажмите «Скачать».

Опция «Спрашивать, куда сохранять» открывает стандартный диалог сохранения Chrome.

## Ограничения

- Не поддерживаются потоковые видео HLS (`.m3u8`) и DASH (`.mpd`) — они передаются множеством
  маленьких сегментов. Поэтому YouTube, Twitch и подобные сервисы не работают.
- Видео с защитой DRM (Netflix и др.) скачать нельзя.
- `blob:`-ссылки скачать напрямую нельзя; если сайт загружает видео обычным файлом, оно будет
  найдено через сетевые запросы.
- Некоторые сайты проверяют заголовок Referer и отдают ошибку при скачивании.

Используйте расширение только для видео, которые вы имеете право скачивать.

## Структура

```
extension/
├── manifest.json        # Manifest V3
├── background.js        # перехват сетевых ответов, хранение списка по вкладкам, значок
├── content.js           # поиск <video>/<source> на странице
├── popup/               # всплывающее окно (HTML, CSS, JS)
├── _locales/{ru,en}/    # переводы
└── icons/
```
